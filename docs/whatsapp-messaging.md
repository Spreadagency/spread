# الرسايل والإشعارات — واتساب + داخل المنصة

## الفكرة

| | |
|---|---|
| **داخل المنصة** | كل إشعار بيتسجل في `user_notifications`، وده نفس الجدول اللي بيستخدمه الجرس وصفحة «الرسايل والإشعارات» وتطبيق الموبايل (push). |
| **واتساب** | صف في `messages` بحالة `pending`. الموقع **عمره ما بيكلّم Evolution مباشرة**، وn8n هو اللي بيبعت. |

```
حدث في المنصة / أدمن بيبعت
   → Notifier (includes/Notifier.php)
   → فوري: POST لـ n8n (webhook · مهلة 3 ثواني)          ← رسالة واحدة
   → جماعي / مجدول / الـ webhook وقع: يفضل pending          ← n8n بيسحبه كل دقيقتين
   → n8n → Evolution API (instance «Spread 011») → callback.php (sent / failed)
```

- منع الإرسال المزدوج: الرسالة بتتعلّم `processing` بـ UPDATE واحد (atomic) قبل ما تتبعت.
- الحملات بتتبعت **بالتدريج**، رسالة واحدة كل 5–10 ثواني، علشان الرقم مايتحظرش.

## إيه اللي بيتبعت للعميل

| الحدث | إمتى |
|---|---|
| `notification` — **أي إشعار جديد في المنصة** | كل `notify_user()`: تفعيل الباقة · رفض الدفع · طلب معلومات… |
| `account_activated` | الأدمن وافق على الحساب |
| `ideas_ready` | آخر دفعة من أفكار الحملة اتولّدت |
| `designs_ready` | تصميم اتولّد (مرة كل 30 دقيقة بالكتير) |
| `post_published` / `post_failed` | كرون النشر المجدول |
| `credits_low` | الرصيد ≤ 10 كريدت، أو ≤ 15% في وضع النسبة. مرة واحدة لحد ما يشحن. |
| `subscription_expiring` | الكرون اليومي: الاشتراك المدفوع بيخلص بعد 3 أيام |
| `referral_reward` | المُحيل كسب مكافأة |
| `inactive_reminder` | الكرون اليومي: مدخلش من 7 أيام. مرة كل 14 يوم بالكتير. |
| `offer_new` | عرض جديد (كود خصم / حملة)، لو الأدمن علّم «ابعت العرض للعملاء» |
| `announcement_new` | إعلان جديد، لو الأدمن علّم «بلّغ العملاء» |
| `otp` | كود التحقق من رقم الواتساب |

### قوالب وشروط

من **الأدمن ← الرسايل والواتساب ← القوالب والشروط**، كل قالب ليه:

- **العنوان والنص**، بمتغيرات زي `{{name}}` و`{{first_name}}` و`{{credits}}` و`{{link}}` وغيرها حسب الحدث، ومعاينة حيّة.
- **القناة** و**التشغيل**.
- **الشروط**، يعني مين يستلم الإشعار. أمثلة:
  - باقة معيّنة
  - مشتركين / غير مشتركين
  - رصيد أقل من كذا
  - مسجّل من تاريخ لتاريخ
  - مدخلش من كذا يوم
  - رقم واتساب متحقق

### قواعد الإرسال

- **الحد اليومي:** 3 رسايل واتساب لكل عميل. الإشعارات المهمة والرسايل الإدارية مش بتتحسب.
- **ساعات الهدوء:** من 23:00 لـ 09:00. الإشعار العادي بيتأجل لآخرها، والمهم (`post_failed` و`subscription_expiring`…) بيتبعت فورًا.
- **منع التكرار:** نفس الحدث لنفس العميل مايتبعتش تاني خلال 30 دقيقة.
- **الرقم:** الواتساب بيوصل بس للي **أكّد رقمه** بكود OTP، ومفعّل «استقبال رسايل واتساب»، ومقفلش الحدث من إعداداته.

## الشاشات

**العميل**

- جرس فيه عدّاد، بيتحدّث كل 30 ثانية، وبيطلع تنبيه صغير لما توصل رسالة.
- `notifications.php`:
  - **الرسايل:** صفحات، وتمييز «من فريق Spread»، وزرار «قراءة الكل».
  - **إعدادات الواتساب:** الرقم، وكود التحقق (10 دقايق · 3 محاولات · 3 أكواد في الساعة)، والموافقة على الاستقبال، وجدول الأحداث (واتساب / داخل المنصة).
- كارت «الإشعارات والواتساب» في مركز الإعدادات، و«الرسايل والإشعارات» في قايمة الحساب.

**الأدمن:** `admin/whatsapp.php`

- **إرسال رسالة:**
  - الجمهور: عميل واحد بالبحث، أو الكل، أو فلتر. الصفحة بتعرض «هيوصل لـ N عميل (M منهم واتساب)».
  - القناة، العنوان والنص، صورة، ورابط.
  - الإرسال الآن أو بالجدولة، ومعاينة بشكل الواتساب.
- **الحملات:**
  - المتبعت، والفاشل، واللي في الطابور، ونسبة القراءة.
  - إلغاء حملة.
- **سجل الرسايل:**
  - فلاتر بالحالة والنوع والتاريخ والعميل.
  - «إعادة إرسال» للرسايل الفاشلة.
- **الإعدادات والربط:**
  - تشغيل وإيقاف الإرسال.
  - نسخة واتساب لكل إشعار.
  - رابط الـ webhook والمفتاح المشترك.
  - الحد اليومي وساعات الهدوء.
  - رسالة تجريبية.

## n8n

**الـ Workflow:** «Spread AI — WhatsApp Messaging»، شغّال على n8n.srv1038804.hstgr.cloud.

| | |
|---|---|
| Webhook (Production) | `https://n8n.srv1038804.hstgr.cloud/webhook/spread-wa-send` |
| الجدولة | كل دقيقتين، بتسحب `GET {site}/api/wa/pending.php?limit=10` |
| الإرسال | Evolution API، credential اسمه «Spread»، instance اسمه «Spread 011». نص / صورة / فيديو / ملف. |
| النتيجة | `POST {site}/api/wa/callback.php` ← `{message_id, status, provider_id, error}` |
| الإعدادات | نود **Spread Config**: `site` · `spread_key` · `instance` · `batch` |

كل الطلبات بين الموقع وn8n فيها الهيدر `X-Spread-Key`، ولازم قيمته تبقى **نفس المفتاح في المكانين**:

- **في n8n:** نود Spread Config.
- **في الموقع:** الأدمن ← الرسايل والواتساب ← الإعدادات والربط.

## التشغيل على السيرفر

1. ارفع الملفات. الجداول بتتعمل تلقائيًا أول مرة، وفيه نسخة يدوي في `sql/2026_whatsapp_messaging.sql`.
2. افتح **الأدمن ← الرسايل والواتساب ← الإعدادات والربط**:
   - لينك الـ Webhook: `https://n8n.srv1038804.hstgr.cloud/webhook/spread-wa-send`
   - المفتاح المشترك: نفس اللي في نود Spread Config في n8n
   - فعّل «الإرسال على الواتساب» واحفظ
3. ابعت «رسالة تجريبية» لرقمك وشوف حالتها في السجل.
4. ضيف كرون يومي الساعة 10 الصبح:
   ```
   /usr/local/bin/php /home/USER/public_html/cron/daily_notifications.php cron_secret=YOUR_SECRET
   ```
