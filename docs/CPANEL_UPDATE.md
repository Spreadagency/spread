# رفع تحديث على cPanel خطوة بخطوة

الطريقة دي ثابتة لأي حزمة بنبعتها (`spread-…zip`).

## 1) نسخة احتياطية (دقيقتين، ماتتخطاهاش)
1. ادخل **cPanel**.
2. **Files ← File Manager**، وافتح مجلد الموقع `/home/spreadagency/ai.spreadagency.net`.
3. علّم على الفولدرات اللي هتتغيّر، أو على المجلد كله.
4. كليك يمين ← **Compress** ← Zip Archive ← **Compress File(s)**.
5. نزّل الملف المضغوط على جهازك.

> قاعدة البيانات: cPanel ← **Backup** ← Download a MySQL Database Backup ← قاعدة المنصة وقاعدة الـ AI.
> مش ضروري في تحديث مفيهوش ترحيلات (زي المرحلة 5)، بس مفيد.

## 2) رفع الحزمة
1. في **File Manager**: ادخل `/home/spreadagency/ai.spreadagency.net` نفسه، **مش** جوه أي مجلد تاني.
2. **Upload** (فوق) ← اختار ملف الـ zip ← استنى لحد ما يكمّل 100% ← **Go Back to …**.
3. كليك يمين على الملف ← **Extract**.
4. اتأكد إن المسار هو `/home/spreadagency/ai.spreadagency.net` بالظبط ← **Extract File(s)**.
5. لو سألك عن ملفات موجودة، وافق على الاستبدال.
6. امسح ملف الـ zip بعد ما يتفك (كليك يمين ← Delete).

> الحزم بتاعتنا مافيهاش `includes/config.php` ولا الصور اللي اترفعت، فإعداداتك وملفات العملاء مش هتتلمس.

## 3) التأكد
1. افتح الأدمن ← اضغط على رقم النسخة تحت القايمة الجانبية (**فحص التحديث**).
2. لازم يطلع: **الملفات كلها مطابقة ✅**.
3. لو فيه ترحيلات مستنية، شغّلها من نفس الصفحة («تشغيل الترحيلات»).

| لو ظهر | الحل |
|---|---|
| «ملف ناقص» | الحزمة اتفكّت في مجلد غلط. ارفعها تاني في المسار الصح (الخطوة 2) |
| «ملف مختلف» | ملف قديم مكانه. فك الحزمة تاني ووافق على الاستبدال |
| صفحة بيضا أو 500 | cPanel ← **Errors** (أو `error_log` في نفس المجلد)، وابعتلي آخر سطر |

- **الشرط:** جداول قاعدة الـ AI معمولة من المرحلة 3 (الأدمن ← إعداد الـ MCP كله ✅).

بعد الرفع والتأكد (الخطوات 1 لـ 3)، القايمة الجانبية فيها مجموعة **AI QUALITY**:

| الصفحة | جرّب |
|---|---|
| **التقرير اليومي** | الكروت الأربعة والرسوم بتظهر. التقرير نفسه بيظهر لما Claude يعمل `daily_review` |

| **البلاغات** | اعمل بلاغ تجريبي من حساب عميل (⚑)، وبعدين: غيّر الحالة · افتح صورة الشاشة · ابعت «رد يدوي»، والمفروض الرد يوصل في صندوق رسايل العميل |

| **إعدادات الجودة** | الأوزان · حد الضعيف · A/B · البلاغات · تشغيل/إيقاف كل أداة |

**اختبار إيقاف أداة:**
1. في «إعدادات الجودة» شيل العلامة من «قايمة المنشورات» واحفظ.
2. أي طلب للأداة دي بيترفض («الأداة دي مقفولة من الأدمن»)، وClaude مش هيشوفها خلال دقيقة.
3. رجّع العلامة.

### خادم الـ MCP (لو ركّبته على الـ VPS)
المرحلة دي فيها تعديل صغير في الخادم: بيخفي الأدوات اللي قفلتها. ارفع `spread-mcp-server.zip` الجديدة وشغّل:
```bash
sudo unzip -o spread-mcp-server.zip -d /opt/spread-mcp/app
sudo chown -R spreadmcp:spreadmcp /opt/spread-mcp
cd /opt/spread-mcp/app && sudo -u spreadmcp npm ci && sudo -u spreadmcp npm run build
sudo systemctl restart spread-mcp
```
لو لسه ماركّبتش الـ VPS، اتجاهل الجزء ده. الموقع بيرفض الأداة المقفولة في كل الأحوال.

## Content Engine: المراحل A + B + C
- **الحزمة:** `spread-ce-abc-site.zip`.
- **ترحيلات (اتنين):** `2026_ce_models.sql` و `2026_ce_fixes.sql`. الاتنين آمنين لو اتشغّلوا أكتر من مرة.
- **قبل الرفع:** نسخة احتياطية من قاعدة المنصة. الترحيل التاني بيغيّر FKs في جدولين ماليين.

### بعد الرفع والتأكد (الخطوات 1 لـ 3)
1. **فحص التحديث** ← «تشغيل الترحيلات». المفروض الاتنين يطلعوا ✅.
   - لو فيه طلبين Paymob قدام بنفس الرقم، قيد `uq_paymob` بيتخطى لوحده من غير ما يوقف الترحيل.
2. **الموديلات (السجل والمراحل)**، في مجموعة الـ AI:
   - تبويب «سجل الموديلات» ← «جلب الموديلات» من كل مزود ← علّم اللي عايزه ← «إضافة».
   - راجع الأسعار. الموديل اللي مالوش سعر بياخد أولوية أقل في الإعدادات الجاهزة، والتكلفة بتاعته مابتتحسبش.
   - تبويب «الإعدادات الجاهزة» ← «اقتصادي / متوازن / جودة» ← «تطبيق». أو اختار موديل وحرارة لكل مرحلة من تبويب «خريطة المراحل».
   - المراحل اللي مالهاش إعداد بتفضل شغالة بالإعداد القديم في «توجيه الـ AI»، فمفيش حاجة هتقف.
3. **مفاتيح التشفير**، في مجموعة النظام. لو الكارت أحمر «مفتاح منشور»، اتبع الخطوات اللي في الصفحة:
   1. نسخة احتياطية.
   2. في `includes/config.php`، غيّر اسم سطر `ENCRYPTION_KEY` لـ `ENCRYPTION_KEY_PREV`.
   3. ضيف سطر `ENCRYPTION_KEY` جديد بالمفتاح اللي الصفحة ولّدته.
   4. ارجع الصفحة ← «إعادة التشفير». عمود «بالمفتاح القديم» لازم يبقى 0.
   5. امسح سطر `ENCRYPTION_KEY_PREV`.
   6. الأحوط: اعمل مفاتيح AI جديدة من عند المزودين، و App Secret جديد لتطبيق ميتا.
4. **صفحات التشخيص** (`check.php` و `check-db.php`) بقت بتفتح للأدمن بس:
   - افتحها وانت داخل اللوحة في نفس المتصفح.
   - لو اللوحة نفسها مش بتفتح: اعمل ملف فاضي اسمه `.diag-open` في فولدر الموقع من File Manager. بيشتغل ساعة، وامسحه بعدها.
5. **Meta webhook** بقى بيرفض أي طلب لو App Secret بتاع ميتا مش متسجّل في الإعدادات. لو بتستخدم الـ webhook، اتأكد إن السيكرت موجود.

### اختبار سريع
| جرّب | المفروض |
|---|---|
| ولّد منشور من الحملة | شغال عادي. في «سجل طلبات الـ AI»، النداء متسجّل بالموديل والتوكنز والتكلفة |
| افتح `…/public/api/campaigns.php?action=delete&id=1` في المتصفح | `405` «العملية دي لازم تتبعت POST». مفيش حاجة اتمسحت |
| افتح `…/check.php` من متصفح مش داخل اللوحة | صفحة «مقفولة 🔒» |
| شحن Paymob تجريبي | الرصيد بينزل مرة واحدة، حتى لو فتحت لينك الرجوع مرتين |

## Content Engine: المرحلة D (Brand DNA + الحملة بالاختيارات)
- **الحزمة:** `spread-ce-d-site.zip`.
- **ترحيل واحد:** `2026_ce_engine.sql`. جداول جديدة بس، ومش بيلمس أي بيانات موجودة.

### بعد الرفع
1. **فحص التحديث** ← «تشغيل الترحيلات».
2. **الـ Cron** (مرة واحدة): cPanel ← **Cron Jobs** ← Common Settings: **Once Per Minute** ← Command:
   ```
   /usr/local/bin/php /home/spreadagency/ai.spreadagency.net/cron/ce-worker.php cron_secret=نفس_السر_بتاع_النشر_المجدول
   ```
   - لو مش فاكر السر: الأدمن ← التكاملات ← `cron_secret`.
   - صفحة «محرك المحتوى» في الأدمن بتقول إذا كان شغال ولا لأ.
3. الأدمن ← **محرك المحتوى** (في مجموعة الـ AI):
   - «الإعدادات»: راجع الهامش (الافتراضي 100%) وقيمة الكريدت بالجنيه (الافتراضي 1.5).
   - «العملاء»: افتح المحرك لحسابك أو لعميل تجريبي. الافتراضي إنه مقفول للكل.

### اختبار سريع (بحساب مفتوح له المحرك)
| جرّب | المفروض |
|---|---|
| القايمة ← «محرك المحتوى ✨» ← «ابني الملف» | شريط تقدّم، وبعد ثواني «ملف الهوية جاهز ✓» |
| «راجع وعدّل» ← غيّر التموضع ← احفظ ← «ابنيه من جديد» | التموضع اللي كتبته يفضل زي ما هو |
| «+ حملة جديدة» ← كمّل الخطوات | الملخص بيظهر الكريدت والتوكنز وعدد القطع |
| «احفظ البريف» | الحملة تظهر في «حملاتك» «جاهزة للتشغيل» |
| الأدمن ← محرك المحتوى ← «الحملات» | نفس الحملة بالتكلفة المتوقعة بالدولار |
